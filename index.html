🏷️ Product Barcode Labels

हर Design + Colour + Size के लिए अलग Code 128 Barcode label generate/print करें. Barcode scan करने पर billing में product, colour और size auto-fill होगा. Label पर MRP और Selling Price भी दिखेंगे.

🏷️ SKU चुनकर Labels Print करें

मोबाइल पर कई SKU चुनने के लिए हर SKU पर टैप करें; चुने हुए SKU पर दोबारा टैप करने से हट जाएगा।

SKU चुनते ही उसके सभी Colour और Size अपने आप यहाँ दिखेंगे.

🖨️ Bluetooth Printer

Mobile Chrome से Bluetooth BLE thermal printer connect करें. Printer में Bluetooth ON रखें, फिर नीचे Connect दबाएँ.
